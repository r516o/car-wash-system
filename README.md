## المميزات الرئيسية

### نظام الجدولة الذكي المتقدم
- **منع تعارض المواعيد**: خوارزمية متقدمة تمنع حجز مواعيد متعارضة بناءً على الوقت، الموقع الجغرافي، والموظفين
- **توزيع ذكي**: تجميع عملاء المنطقة الجغرافية نفسها في فترات زمنية متقاربة
- **تحسين المسار**: حساب أفضل مسار للتنقل بين المواقع لتقليل وقت التنقل
- **مرونة في الجدولة**: دعم لمواعيد الصباح والمساء مع حجز تلقائي للمشتركين

### إدارة الاشتراكات
- **باقات متعددة**: باقات أساسية (10 غسلات)، مميزة (15 غسلة)، عائلية (20 غسلة)
- **توزيع مرن**: العميل يوزع الغسلات بين سيارتيه كما يشاء (6+4، 5+5، 8+2)
- **تجديد تلقائي**: نظام تجديد الاشتراكات مع إشعارات التذكير
- **إدارة الاستخدام**: تتبع الغسلات المستخدمة والمتبقية لكل سيارة

### نظام المدير الشامل
- **لوحة تحكم تفاعلية**: إحصائيات حية ومؤشرات الأداء
- **إدارة الجدول**: عرض شامل لجميع المواعيد مع كشف التعارضات
- **تقارير متقدمة**: إيرادات، أداء، رضا العملاء، تحليل المناطق
- **إدارة الموظفين**: جدولة، أداء، حضور وغياب

### تطبيق العميل المتكامل
- **حجز سهل**: واجهة سهلة لحجز المواعيد والخدمات
- **تتبع الخدمة**: معرفة موقع الموظف ووقت الوصول المتوقع
- **نظام نقاط**: برنامج ولاء مع نقاط مكافأة
- **تقييم الخدمة**: نظام تقييم بعد كل خدمة

### تطبيق الموظف
- **جدول اليوم**: عرض المواعيد المجدولة مع التفاصيل
- **خريطة التنقل**: أفضل مسار للتنقل بين العملاء
- **تحديث الحالة**: تحديث حالة الخدمة بسهولة
- **إدخال الدفع**: تسجيل المدفوعات للخدمات الفردية

## البنية التحتية التقنية

### Backend
- **إطار العمل**: Hono (Edge Runtime)
- **قاعدة البيانات**: Cloudflare D1 (SQLite)
- **التخزين**: Cloudflare KV و R2
- **اللغة**: TypeScript

### Frontend
- **تطبيق الويب**: React مع Tailwind CSS
- **تطبيق الجوال**: React Native (قابل للتطوير مستقبلاً)
- **الخرائط**: Google Maps API
- **الإشعارات**: Firebase Cloud Messaging

### التكاملات الخارجية
- **الدفع**: Apple Pay، Google Pay، بطاقات الائتمان
- **الرسائل النصية**: Twilio
- **البريد الإلكتروني**: SendGrid
- **التحليلات**: Google Analytics

## المتطلبات الوظيفية

### نظام الجدولة
- ساعات العمل: 12 ساعة يومياً (6 صباحاً - 7 مساءً مع استراحة ساعتين)
- السعة الاستيعابية: 3-4 عملاء في الساعة
- المباعدة الزمنية: 15 دقيقة على الأقل بين المواعيد
- التجميع الجغرافي: عملاء المنطقة الواحدة في فترات متقاربة

### الاشتراكات
- عدد الغسلات: 10 غسلات شهرياً موزعة كل 3 أيام
- التوزيع: مرن بين سيارتين (مثال: 6+4، 5+5، 8+2)
- الوقت المفضل: صباحي (6-12) أو مسائي (13-19)

### منع التعارضات
- التحقق المسبق من التوفر الجغرافي والزمني
- حجز ذري للموقع والوقت
- 15 دقيقة حد أدنى للتنقل بين المواعيد
- 5 دقائق قبل وبعد كل موعد للتحضير والتنظيف
